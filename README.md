# Flametal Pickaxe

A lightweight Valheim mod that adds a craftable Flametal Pickaxe, providing a late-game mining tool capable of harvesting Petrified Gammeltrolls in the Deep North.

## Features

- Tier 6 mining capability
- Crafted at the Black Forge
- Uses the existing Black Metal Pickaxe model with a custom inventory icon
- No upgrades required
- Compatible with Veinminer for faster harvesting
- No changes to vanilla pickaxe stats

## Crafting Recipe

- 25 Flametal
- 10 Ashwood

Requires a Black Forge.

## Installation

Install through r2modman or Thunderstore Mod Manager. BepInEx and Jötunn are required dependencies.

For manual installation, place `FlametalPickaxe.dll` and `flametalpickaxe.png` together in a folder under `BepInEx/plugins`.

## Notes

Veinminer is optional. Without it, Petrified Gammeltroll segments can be mined individually.

This mod adds a custom item. Players who wish to use the Flametal Pickaxe need the mod installed. Multiplayer compatibility with unmodded clients has not yet been fully tested.
